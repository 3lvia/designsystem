# Elvia Design System Skill

This skill is in preview.

I will add more content over time.

> [!IMPORTANT]
> The skill might move to another repository in the future. If it does, you may need to update
> your skill installation with the new repository location to continue receiving updates.

## Install

[GitHub CLI skill](https://cli.github.com/manual/gh_skill) is in preview.

Preview the skill before you install it:

```sh
gh skill preview 3lvia/designsystem elvia-design-system
```

Install the skill with:

```sh
gh skill install 3lvia/designsystem elvia-design-system
```

## Update

To update the installed skill, run:

```sh
gh skill update elvia-design-system
```
